# Twitter/X Thread Reading

## Unrolling Threads

When the user shares a Twitter/X thread URL and wants it read or summarized, use **https://twitter-thread.com/** to unroll the thread into a readable format.

### Usage
1. Take the Twitter/X thread URL from the user
2. Navigate to `https://twitter-thread.com/` and submit the URL
3. Read the unrolled thread content
